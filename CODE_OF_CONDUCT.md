# Code of conduct

## The short version

Be decent. Argue about the code, never about the person holding it.

## What is expected

- **Criticise the work, not the author.** "This breaks RTL below 820 px" is useful. "This is
  amateurish" is not.
- **Bring evidence.** A screenshot, a failing `verify` line, a contrast ratio. Taste is welcome, but
  say it is taste.
- **Assume the other person had a reason.** Most odd-looking decisions in this repo have one, and
  most of them are written down in `docs/adr/`. Ask before concluding it was carelessness.
- **Accept an answer of no.** Some things are deliberately out of scope — a dependency, a webfont, a
  chart library. A closed issue is not a rejection of you.

## What is not tolerated

Harassment, personal attacks, demeaning comments about anyone's identity, background or level of
experience. Sexualised language or imagery. Publishing anyone's private information. Sustained
disruption of discussion.

## Scope

Anywhere this project happens: issues, pull requests, commit messages, discussions, and any space
where someone is representing the project.

## Enforcement

There is one maintainer. Report anything that needs attention to **umarsabirin369@gmail.com**, or
privately through GitHub if it involves conduct rather than security.

Reports are read, the reporter's identity is kept confidential, and the response is proportionate:
usually a warning first, a temporary block if it continues, a permanent one if it does not. Nobody
gets a pass for being a good contributor.

If you disagree with a decision, say so in the same channel. You will get a reason, not silence.

## Why this is short

A code of conduct nobody reads protects nobody. This one says what it means in a page, which is the
length a person will actually read before they are angry rather than after.

For a longer and more carefully lawyered version of the same idea, see the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) — this
project's expectations are compatible with it.
