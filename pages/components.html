Why did this instance restart?
The liveness probe failed three consecutive times. Liveness restarts the container; readiness would only have pulled it from rotation.
Is a snapshot a backup?
No. A snapshot is copy-on-write on the same node and dies with it. A backup lives in object storage and survives node loss.
What counts as N+1?
Every workload still fits after losing any single node. At 92% memory quota this cluster no longer does.
